# NEXUS — صفحة هبوط للهاتف

واجهة عربية ثابتة باتجاه RTL، من دون مكتبات خارجية أو عملية بناء. جاهزة للنشر عبر GitHub Pages.

المسار المنفّذ:

1. حركة تحميل وتسجيل الدخول برمز من 4 أرقام.
2. اختيار AVIATOR أو APPLE OF FORTUNE أو CRASH.
3. القائمة الرئيسية للبرنامج المختار.
4. إدخال معرّف رقمي من 10 أرقام.
5. حفظ البرنامج والمعرّف داخل المتصفح.
6. بوابة VIP تعليمية منفصلة بعد إرسال المعرّف، مع الرمز الترويجي ومستويات العرض والدعم.
7. شريط أحداث متحرك أسفل اللوحة العلوية، ويمكن تعديل محتواه من المصفوفة الموجودة في `script.js`.
8. دردشة تلقائية ثابتة أسفل الشاشة، تظهر رسائل جديدة كل 3–5 ثوانٍ وتجيب محليًا عن أسئلة التفعيل والمعرّف والتسجيل والرمز الترويجي والدعم.

## معاينة سريعة

افتح الطرفية داخل هذا المجلد وشغّل:

```bash
python3 -m http.server 8080
```

ثم افتح [http://localhost:8080](http://localhost:8080).

رمز الدخول: `7799`.

## النشر عبر GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. افتح **Settings → Pages**.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)`، ثم اضغط **Save**.

لا يستخدم الموقع خادمًا أو قاعدة بيانات. بوابة VIP محاكاة تعليمية لا تعالج دفعات، ولا تفتح تسجيلًا خارجيًا، ولا ترسل بيانات أو إثباتات دفع.
